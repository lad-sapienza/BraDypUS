# Security policy

Please **do not report security vulnerabilities in public issues**.

Use GitHub's private reporting: <https://github.com/lad-sapienza/BraDypUS/security/advisories/new>
(Security tab → "Report a vulnerability").

Include the affected version, the steps to reproduce and, if you can, the impact. Do not include
real credentials or data from a production database.

Security fixes are handled urgently and ahead of any other work, and are released as patch versions
of the supported line (currently 5.x).
