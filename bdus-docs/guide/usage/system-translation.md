# Interface language <Badge type="tip" text="v5.0.0" />

BraDypUS supports **English** and **Italian** as UI languages.

## Switching the language

Click the language flag in the top-right corner of the navigation bar to toggle
between English 🇬🇧 and Italian 🇮🇹. The choice is stored in the browser and
persists across sessions.

## Application-level default

The default language for a new application is set in
[App settings](/guide/setup/main-app-config) → **Language**. Individual users
can always override it client-side.

## Field labels

Field labels defined in Config are stored as-is and are not translated — you
choose whether to write them in English or Italian (or any other language).
The UI chrome (buttons, headings, messages) follows the selected language.
