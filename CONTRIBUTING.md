# Contributing

- **Bugs**: open an issue with the *Bug report* form. Include the version, the database engine and the
  smallest steps that reproduce it.
- **Ideas**: open an issue with the *Idea* form. BraDypUS is in a consolidation phase (bug fixes and
  edge cases first), so ideas are discussed, not promised.
- **Security**: never in a public issue; see [SECURITY.md](SECURITY.md).
- **Language**: issues and pull requests are in English.
- **Pull requests**: please open an issue first for anything beyond a small fix. A change is complete
  when code, tests (all three engines), `CHANGELOG.md`, `openapi.yaml` and the user guide agree; see
  `bdus-api/CLAUDE.md` ("Definition of done").
- Commits that finish an issue say `Closes #N`.
